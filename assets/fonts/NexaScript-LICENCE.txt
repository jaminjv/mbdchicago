Nexa Script — Fontfabric
https://www.fontfabric.com/fonts/nexa-script/

Licensed by the site owner. Five cuts are included:

  nexa-script-thin.woff2
  nexa-script-light.woff2
  nexa-script-regular.woff2
  nexa-script-semibold.woff2   <- the one the site uses
  nexa-script-heavy.woff2

Semibold was chosen because its stroke weight is the closest of these
to the logo lockup. Bold would be a shade closer still, but it was not
part of the licensed set supplied; adding that file and repointing the
@font-face in assets/css/styles.css is all it would take.
